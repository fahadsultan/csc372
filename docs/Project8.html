Self-Attention from Scratch

In this assignment you’ll build the core operation of the Transformer, self-attention, with learned query, key and value projections. Then you’ll train it on two small tasks and look inside it: for every token, which other tokens does it attend to?


The two tasks were chosen so that the correct attention pattern is predictable in advance:

Task 1: Reverse

Input: 3 1 4 1 5 9 2 6

Target: 6 2 9 5 1 4 1 3

If your implementation is right, you’ll see the attention pattern to be Position-based i.e. position i attends to position L-1-i

Task 2: Max

Input: 3 1 4 1 5 9 2 6

Target: 9 9 9 9 9 9 9 9

If your implementation is right, you’ll see the attention pattern to be Content-based i.e. every position attends to the largest token

Task 3 — Running Max

Input 3 1 4 1 5 9 2 6

Target 3 3 4 4 5 9 9 9

At each position, output the largest token seen so far, including the current token. The expected attention pattern is content-based with a causal mask. Position i attends to the largest token among positions 0 through i. For example, at the second 1, the running max is 4 because the 5 and 9 are still ahead.

Use masked_fill to set the scores for future positions to -inf before applying softmax.


Rules: don’t use torch.nn.MultiheadAttention or F.scaled_dot_product_attention in your own implementation. (We use the latter only to test yours.) Fill in every cell marked # YOUR CODE HERE and every Your answer block. Cells run in a few minutes on a laptop CPU.

Question 1. Scaled Dot-Product Attention

Given

queries \(Q \in \mathbb{R}^{B \times N \times d_k}\)

keys \(~~~~K \in \mathbb{R}^{B \times N \times d_k}\) and

values \(~V \in \mathbb{R}^{B \times N \times d_v}\)

where

\(B\) is batch size, the number of sequences processed at once (e.g., 128 in the training loop).

\(N\) is equence length, the number of tokens per sequence (8 in this assignment, since SEQ_LEN = 8).

\(d_k\) is key/query dimension, the size of each query and key vector, i.e. the output size of W_q and W_k. Queries and keys need the same size because attention scores are their dot products.

\(d_v\) is value dimension, the size of each value vector, which is also the size of each token’s output from attention. It can differ from \(d_k\), but the assignment sets them equal (\(d_v\) = \(d_k\) = 32).

\[\text{scores} = \frac{QK^\top}{\sqrt{d_k}}\]
\[A = \text{softmax}_{\text{row}}(\text{scores})\]
\[\text{output} = AV\]

Row \(i\) of \(A\) is a probability distribution: how much token \(i\) (the query) attends to each token \(j\) (the keys). Keep this convention for the whole assignment: rows = who is looking, columns = who is being looked at.


Masking:

If mask is given, it is a boolean tensor broadcastable to (B, N, N) where True means allowed. Set disallowed scores to \(-\infty\) before the softmax so that they get exactly zero weight.

Question 3. A tiny attention model and its training step

Our model is deliberately minimal, so that attention is the only way information moves between positions:

tokens ──► token embedding + learned positional embedding ──► SelfAttention ──► Linear ──► logits over vocabulary

There’s no residual connection and no MLP, so a position’s prediction depends only on what it attends to. Data generators for both tasks are provided.

VOCAB, SEQ_LEN = 10, 8   # tokens are the digits 0..9

def make_batch(task, batch_size=128, seq_len=SEQ_LEN):
    x = torch.randint(0, VOCAB, (batch_size, seq_len))
    if task == "reverse":
        y = x.flip(dims=[1])
    elif task == "max":
        y = x.max(dim=1, keepdim=True).values.expand(-1, seq_len)
    elif task == "running_max":                     # used in Part 6
        y = torch.cummax(x, dim=1).values
    else:
        raise ValueError(task)
    return x.to(device), y.to(device)

def plot_attention(weights, tokens, ax=None, title=None):
    '''weights: (L, L) tensor for ONE example; tokens: length-L list of ints'''
    if ax is None:
        _, ax = plt.subplots(figsize=(5, 4.5))
    L = len(tokens)
    w = weights.cpu().numpy()
    im = ax.imshow(w, cmap="viridis", vmin=0, vmax=1)
    labels = [f"{t} (p{i})" for i, t in enumerate(tokens)]
    ax.set_xticks(range(L)); ax.set_xticklabels(labels, rotation=90, fontsize=8)
    ax.set_yticks(range(L)); ax.set_yticklabels(labels, fontsize=8)
    ax.set_xlabel("key: attended TO")
    ax.set_ylabel("query: attending FROM")
    for i in range(L):
        for j in range(L):
            if w[i, j] > 0.05:
                ax.text(j, i, f"{w[i, j]:.2f}", ha="center", va="center", fontsize=6,
                        color="black" if w[i, j] > 0.5 else "white")
    plt.colorbar(im, ax=ax, fraction=0.046, pad=0.04)
    if title:
        ax.set_title(title)
    return ax
