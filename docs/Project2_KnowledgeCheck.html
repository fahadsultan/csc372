CSC-372 · PROJECT 2 KNOWLEDGE CHECK PyTorch: A Modern Deep Learning Library

Conceptual understanding check. These questions test the ideas behind the notebook (tensors, computation graphs, gradients, training, tokenization, next-token prediction), not library syntax.

20 questions: 12 multiple choice, 8 fill-in-the-blank. Answer key with explanations at the end.

====================================================================== PART A — MULTIPLE CHOICE ======================================================================

Question 1 Conceptually, what is a “tensor,” and what does its rank (order) mean? A. A GPU-only data type; its rank is the amount of GPU memory it uses B. A generalization of scalars, vectors, and matrices to any number of dimensions; its rank is the number of indices needed to address an element C. A list of numbers that must be one-dimensional; rank is its length D. A synonym for “neural network layer”; rank is the number of neurons

Question 2 What does a computation graph represent, and why is it built? A. The wiring diagram of the GPU, built to schedule memory transfers B. The sequence of operations connecting inputs and parameters to the loss, built so that gradients can be computed automatically C. A chart of training loss over time, built for visualization D. The folder structure of the dataset, built to speed up loading

Question 3 Backpropagation computes gradients through a network by repeatedly applying which idea from calculus? A. Integration by parts B. The chain rule for derivatives of composed functions C. L’Hopital’s rule D. The fundamental theorem of calculus

Question 4 The gradient of the loss with respect to a particular weight tells you: A. The current value that weight should be set to B. How much, and in which direction, the loss changes as that weight increases, so the weight can be nudged the opposite way to reduce the loss C. Whether that weight is stored on the CPU or the GPU D. The probability that the model’s prediction is correct

Question 5 In the update rule new_value = old_value - learning_rate * gradient, what is the role of the learning rate? A. It sets how many training examples are in each batch B. It scales the step size; too large can overshoot or diverge, too small makes training very slow C. It is the target value the loss should reach D. It determines the number of layers in the network

Question 6 Why does deep learning typically use 32-bit floating point rather than 64-bit? A. 64-bit numbers cannot represent negative values B. 32-bit gives enough precision for training while using less memory and compute, and hardware is optimized for it C. 32-bit is required for gradients to exist D. There is no real reason; it is an arbitrary historical choice

Question 7 Why are a network’s weights initialized to small random values rather than all set to the same number? A. Random numbers train faster to compute B. Identical weights make every neuron in a layer compute the same function and receive the same update, so they can never learn to do different things C. Zero and equal values are not representable in floating point D. It guarantees the first prediction is already correct

Question 8 A classification model’s final layer outputs “logits.” What are logits? A. The final class probabilities, guaranteed to sum to 1 B. Raw, unnormalized scores, one per class, that have not been passed through softmax or sigmoid C. The gradients of the loss with respect to the output D. The integer index of the predicted class

Question 9 Frameworks usually fold the softmax step into the loss function instead of putting softmax in the model and using a plain log-loss afterward. The main reason is: A. It reduces the number of layers you have to name B. Numerical stability (and efficiency): computing the log-probability directly avoids overflow/underflow that a separate softmax-then-log can cause C. Softmax cannot be used more than once in a program D. It makes the model output integers

Question 10 When using a trained model only to make predictions, you turn off gradient tracking. Conceptually, why? A. Predictions are more accurate without gradients B. You will not update any parameters, so recording operations for backpropagation only wastes memory and computation C. Gradient tracking would change the model’s weights during prediction D. It converts the model to 64-bit precision

Question 11 How do small vs. large batch sizes differ, conceptually? A. Small batches always produce a lower final loss B. Small batches use less memory but give noisier (higher-variance) gradient estimates; large batches give smoother estimates but use more memory C. Large batches disable shuffling D. Batch size has no effect on training, only on disk usage

Question 12 Why is the training data shuffled at the start of each epoch? A. To make the dataset smaller B. So the model does not learn artifacts of the data’s ordering and does not fall into repetitive update cycles; consecutive batches become less correlated C. Shuffling is required for the loss to be differentiable D. To guarantee every batch contains exactly one class

====================================================================== PART B — FILL IN THE BLANK ======================================================================

Question 13 Backpropagation is, in essence, the repeated application of the __________ rule from calculus.

Question 14 The structure that records the operations linking inputs and parameters to the loss, and that makes automatic gradient computation possible, is called the __________ __________.

Question 15 Setting every weight in a layer to the same initial value is harmful because it fails to break the __________ between neurons, leaving them identical throughout training.

Question 16 Raw model outputs that have not yet been converted into probabilities by softmax or sigmoid are called __________.

Question 17 One complete pass of the training procedure over the entire training dataset is called one __________.

Question 18 Choosing a very small batch size makes each estimate of the gradient more __________, which leads to noisier parameter updates.

Question 19 Large language models are pretrained with a self-supervised objective: given a span of text, predict the __________ token.

Question 20 When the sliding windows used to build training pairs overlap heavily (a small stride), the main risk that increases is __________. Feeding raw integer token IDs straight into a linear layer is conceptually wrong because IDs are __________ labels, not quantities.

====================================================================== ANSWER KEY ======================================================================

PART A

  1. B — A tensor generalizes scalar (rank 0), vector (rank 1), and matrix (rank 2) to any number of dimensions. Rank = how many indices you need to pick out one element.

  2. B — It is a directed record of every operation from parameters/inputs to the loss. Autograd walks it backward to get gradients.

  3. B — Each layer is a function; the network is those functions composed. The chain rule turns the derivative of the composition into a product of local derivatives, computed layer by layer from the output back to the inputs.

  4. B — The gradient is the direction of steepest increase of the loss. Moving a small step in the opposite direction decreases the loss.

  5. B — The learning rate is the step-size multiplier in gradient descent. It is a key hyperparameter: too big diverges, too small crawls.

  6. B — 32-bit floats trade a little precision for half the memory and faster arithmetic, and GPUs are built for them. Precision/efficiency tradeoff.

  7. B — This is “symmetry breaking.” If all weights start equal, all neurons in a layer stay equal forever and the layer effectively has one neuron. Small random values let them diverge and specialize.

  8. B — Logits are unnormalized real-valued scores. Applying softmax turns them into a probability distribution over the classes.

  9. B — Doing softmax and then log separately can overflow or underflow. The fused form (log-sum-exp) is numerically stable and also a bit faster.

  10. B — Inference does no parameter updates, so there is no need to build the computation graph. Skipping it saves memory and time. (It does not change weights or accuracy.)

  11. B — Small batch: cheaper per step, noisier gradient, more updates. Large batch: smoother gradient, costlier memory. It is a tradeoff to tune, not a correctness issue.

  12. B — Shuffling decorrelates consecutive batches and prevents the model from exploiting example order or cycling through the same update pattern, which helps generalization.

PART B

  1. chain — Backprop = chain rule applied through the layers of the network.

  2. computation graph — The directed graph of operations from inputs and parameters to the loss; autograd traverses it in reverse to compute gradients.

  3. symmetry — Symmetry breaking: identical initial weights make all neurons in a layer learn the same thing.

  4. logits — Unnormalized scores before softmax/sigmoid; not probabilities.

  5. epoch — One full sweep over the training set. Training runs for many epochs so parameters are refined repeatedly.

  6. noisy (high-variance) — A small batch is a rougher sample of the full dataset, so its gradient estimate is noisier.

  7. next — Next-token prediction: the label at each position is simply the following token, so no human labels are needed (self-supervised).

  8. overfitting; categorical — Heavily overlapping windows recycle almost the same text, raising overfitting risk (stride = window size removes the overlap). Token IDs are arbitrary category labels, so they must be looked up in an embedding table, not multiplied as if they were magnitudes.
